# Hack-a-thon Workshops
Every year the McGill Data Analysis Club (DAC) Hosts a Hack-a-thon to allow students to put the data analysis skills from their classes to the test and improve their R coding abilities. 

Each year Natalie Delmonte and Rafael Campos-Gottardo teach three workshops to introduce students to the R coding language and data analysis in R. 

The workshops are designed for students to gain an understanding of the R programming language and build their skills to compete in the Hack-a-thon. All ability levels are welcome.
